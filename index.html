Reglamento

Lee estas tres reglas antes de participar. Su cumplimiento es obligatorio para todo el equipo.

  1. 01

    No está permitido el uso de IA. Solo puede usarse para tener claridad de los desafíos, como guía para saber qué tipo de desafío es.

  2. 02

    No se puede realizar automatización para resolver los desafíos.

  3. 03

    En caso de sospecha de uso indebido de IA, se consultará al equipo sobre el proceso realizado en el desafío.

Cómo participar

  1. 1. Revisa el reglamento

    Asegúrate de que todo el equipo conozca las tres reglas de la competencia.

  2. 2. Ten a mano el código de clase

    Copia el código CIXkTh3Ay para ingresarlo en CyLab cuando te lo solicite.

  3. 3. Ingresa a CyLab

    Presiona el botón de acceso y espera a que los desafíos estén disponibles.
